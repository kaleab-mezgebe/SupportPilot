# SupportPilot Delivery Roadmap & Milestones

SupportPilot follows an 8-week structured agile delivery plan divided into 2-week iterations.

## Milestones Breakdown

| Sprint | Focus | Core Deliverables | Status |
| :--- | :--- | :--- | :--- |
| **Sprint 1** | Foundation | Solution setup, React + TS UI, ASP.NET Core API, CORS, Health probe, Docker Compose | **Completed** |
| **Sprint 2** | Identity & RBAC | User registration, login, JWT bearer auth, role authorization, tenant isolation | **Completed** |
| **Sprint 3-4** | Ticketing MVP | End-to-end customer ticket submission, agent assignment, threaded replies, status workflows | **Completed** |
| **Sprint 5** | Support Workspace | Advanced inbox queues, status filters, bulk triage, SLA timer triggers | **Completed** |
| **Sprint 6** | Knowledge Base & AI | Semantic search, vector document ingestion, confidence-aware grounding | **Completed** |
| **Sprint 7** | Real-Time SignalR | Live messaging channels, instant notifications, agent typing indicators | **Completed** |
| **Sprint 8** | Hardening & Release | Automated integration test suite, security audits, production deployment | **Completed** |
